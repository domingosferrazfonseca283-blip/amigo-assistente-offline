# Noémia — Memória de Padrões

A Noémia passa a manter uma camada própria para padrões temporais observados.

## Objetivo

Transformar sequências de estados em conhecimento operacional sem confundir repetição com certeza.

```text
Estados → Sequências → Padrões → Confiança → Hipótese de continuidade
```

## Padrões suportados

- **stable** — o mesmo estado permanece por várias observações;
- **cycle** — estados alternam numa sequência recorrente;
- **reversal** — um estado muda e regressa a um valor anterior;
- **trend** — existem mudanças sucessivas, sem afirmar uma direção causal.

## Princípio epistemológico

Um padrão é uma observação estatística local. Não prova intenção, causalidade ou permanência futura.

A evidência e a confiança acompanham cada padrão para permitir revisão posterior.

## Próxima evolução

A camada pode alimentar previsão local, deteção de anomalias, planeamento e objetivos de longo prazo.
